# 舞台走位编排（Stage Planner）

供小型剧团排练使用的舞台走位编排 Web 应用：按实际尺寸建立舞台，绘制区域与障碍，
维护演员及常用步速，按场景节点安排位置、朝向与到位时间，自动检测无法按时到位、
穿越障碍和演员碰撞，并可拖动时间轴回放全场走位、生成打印材料。

## 技术栈

- 后端：Python 3.11 / Flask，SQLite 持久化（整文档事务性保存）
- 前端：原生 HTML / CSS / JavaScript + Canvas（无构建步骤、无外部 CDN）

## 启动

```bash
pip install -r requirements.txt
python -m stageplanner                 # http://127.0.0.1:5000
# 可选参数
python -m stageplanner --port 8080 --db /path/to/rehearsal.db
# 或使用 flask 命令
flask --app stageplanner.app run
```

首次打开可点击「新建舞台」（名称、宽/深，单位米）。数据保存在运行目录的
`stageplanner.db`（可用环境变量 `STAGEPLANNER_DB` 覆盖）。

## 功能一览

| 需求 | 入口 |
| --- | --- |
| 按实际尺寸建立舞台 | 顶栏「新建舞台」；左栏可改名称、宽高 |
| 绘制区域与障碍 | 左栏工具「绘制区域 / 绘制障碍」，点击加顶点、Enter 完成；选中后可拖动整体/顶点，双击边加顶点 |
| 演员与常用步速 | 左栏「+ 添加」，属性面板改姓名、步速(m/s)、颜色 |
| 场景与节点 | 右栏「+ 场景」「+节点」，节点属性面板可改名称与到位时间，支持拖拽排序、跨场景移动 |
| 位置 / 朝向 / 到位时间 | 从演员列表拖到画布或双击画布上台；拖动标记定位；属性面板精修 X/Y 与朝向 |
| 自动路径 | 同场景相邻节点按演员直线连接；「编辑路径」工具可点击线段加弯折、右键删锚点 |
| 问题检测 | 右栏问题清单实时显示超时（路径长度/步速 > 时间窗）、穿障碍、碰撞；点击定位闪烁 |
| 拖拽 / 多选 | 点选、Shift 多选、空白框选、拖动多选标记 |
| 缩放 | 滚轮缩放、＋/－按钮、「适应」；空格+拖拽或中键平移 |
| 撤销重做 | Ctrl+Z / Ctrl+Y（或工具栏按钮） |
| 节点复制 | 选中节点后「⧉ 复制节点」或 Ctrl+D，连走位与路径复制 |
| 时间轴回放 | 底部时间轴拖动 / ▶ 播放，沿路径插值移动 |
| 比较相邻节点 | 勾选「比较相邻节点」，虚线上一节点位置并统计移动/入场/离场 |
| 持久保存 | 「保存」(Ctrl+S)，整文档写入 SQLite；关闭前有未保存提醒 |
| 演员提示单 | 顶栏「🖨 演员提示单」，按场景→演员分组列出到位时间/位置/朝向/移动耗时/警告 |
| 可打印总览 | 顶栏「🖨 可打印总览」，每节点一张 SVG 舞台图（区域、障碍、路径、问题） |

## 问题检测规则

- **无法按时到位**：相邻节点路径长度 ÷ 演员常用步速 > 到位时间差，路径标红并显示
  所需步速。
- **穿越障碍**：路径任一折线段与障碍多边形规范相交；起止点停靠在障碍顶点合法。
- **演员碰撞**：按 0.5s 时间采样全场轨迹，两演员距离 < 0.7m 时警告。
- 检测逻辑前后端一致（`stageplanner/analysis.py` 与 `static/app.js` 内各一份），
  前端实时显示，打印页使用服务端结果。

## 项目结构

```
stageplanner/
  app.py          Flask 应用工厂、REST 与打印路由
  db.py           SQLite schema 与整文档 upsert
  geometry.py     线段相交 / 点在多边形内 / 折线长度
  analysis.py     走位问题检测、打印派生数据
  templates/      index.html、print_cues.html、print_overview.html
  static/         app.js（Canvas 编辑器）、style.css
tests/test_app.py pytest 端到端测试
```
