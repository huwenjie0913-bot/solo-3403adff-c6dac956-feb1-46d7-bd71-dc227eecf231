# 舞台走位排练板（Stage Planner）

供小型剧团排练使用的舞台走位编排与排练复盘 Web 应用：按实际尺寸建立舞台，绘制区域与障碍，
维护演员及常用步速，按场景节点安排位置、朝向与到位时间，自动检测无法按时到位、
穿越障碍和演员碰撞，并可拖动时间轴回放全场走位、生成打印材料。

新增**排练实录与复盘**：舞台监督选择场景开始排练（倒计时后起表），按节点推进并用
空格或屏幕按钮记录节点时刻、在演员清单逐人打点到位；支持暂停、补记、回退、修正误打点，
可在已记录节点上拖动演员实测位置或标记缺席。记录与开排时的**编排快照**关联，绝不回改原方案。
复盘视图在 Canvas 与时间轴上叠加计划/实测，计算提前/延后、位置偏差与漏记，点击偏差定位回放；
可并排比较两次排练、添加处理备注、把选中的实测时间或位置复制到新的编排副本。所有数据保存在本机 SQLite。

## 技术栈

- 后端：Python 3.11 / Flask，SQLite 持久化（整文档事务性保存）
- 前端：原生 HTML / CSS / JavaScript + Canvas（无构建步骤、无外部 CDN）

## 启动

```bash
pip install -r requirements.txt
python -m stageplanner                 # http://127.0.0.1:5000
# 可选参数
python -m stageplanner --port 8080 --db /path/to/rehearsal.db
# 或使用 flask 命令
flask --app stageplanner.app run
```

首次打开可点击「新建舞台」（名称、宽/深，单位米）。数据保存在运行目录的
`stageplanner.db`（可用环境变量 `STAGEPLANNER_DB` 覆盖）。

## 功能一览

| 需求 | 入口 |
| --- | --- |
| 按实际尺寸建立舞台 | 顶栏「新建舞台」；左栏可改名称、宽高 |
| 绘制区域与障碍 | 左栏工具「绘制区域 / 绘制障碍」，点击加顶点、Enter 完成；选中后可拖动整体/顶点，双击边加顶点 |
| 演员与常用步速 | 左栏「+ 添加」，属性面板改姓名、步速(m/s)、颜色 |
| 场景与节点 | 右栏「+ 场景」「+节点」，节点属性面板可改名称与到位时间，支持拖拽排序、跨场景移动 |
| 位置 / 朝向 / 到位时间 | 从演员列表拖到画布或双击画布上台；拖动标记定位；属性面板精修 X/Y 与朝向 |
| 自动路径 | 同场景相邻节点按演员直线连接；「编辑路径」工具可点击线段加弯折、右键删锚点 |
| 问题检测 | 右栏问题清单实时显示超时（路径长度/步速 > 时间窗）、穿障碍、碰撞；点击定位闪烁 |
| 拖拽 / 多选 | 点选、Shift 多选、空白框选、拖动多选标记 |
| 缩放 | 滚轮缩放、＋/－按钮、「适应」；空格+拖拽或中键平移 |
| 撤销重做 | Ctrl+Z / Ctrl+Y（或工具栏按钮） |
| 节点复制 | 选中节点后「⧉ 复制节点」或 Ctrl+D，连走位与路径复制 |
| 时间轴回放 | 底部时间轴拖动 / ▶ 播放，沿路径插值移动 |
| 比较相邻节点 | 勾选「比较相邻节点」，虚线上一节点位置并统计移动/入场/离场 |
| 持久保存 | 「保存」(Ctrl+S)，整文档写入 SQLite；关闭前有未保存提醒 |
| 演员提示单 | 顶栏「🖨 演员提示单」，按场景→演员分组列出到位时间/位置/朝向/移动耗时/警告 |
| 可打印总览 | 顶栏「🖨 可打印总览」，每节点一张 SVG 舞台图（区域、障碍、路径、问题） |

## 排练实录与复盘

顶部三个标签页：**编排 / 排练实录 / 复盘**。

| 需求 | 入口与操作 |
| --- | --- |
| 选择场景开始排练 | 「排练实录」选场景（可选名称、倒计时秒数）→「▶ 开始排练」；开排冻结编排快照 |
| 记录节点时刻 | 推进到当前节点按 **空格** 或「⏺ 记录节点」；节点时刻=起表后秒数 |
| 逐人打点到位 | 右栏演员行点击，或直接点击/拖动画布上该演员的计划点 |
| 暂停 / 继续 | 「⏸ 暂停」冻结排练时钟；暂停中仍可补记、回退、拖动修正 |
| 补记 | 「✎ 补记节点」选择漏掉的节点并手填时刻 |
| 回退 / 修正误打点 | 「↶ 回退节点」清空最后一个已记录节点；演员行可清除单点、再次点击按当前时钟重打 |
| 实测位置 / 缺席 | 在已记录节点上把演员标记拖到实测位置（粉色偏差连线）；「缺席」按钮标记，再点打点=到场 |
| 备注 | 节点备注、演员逐条处理备注、排练总备注（均自动保存） |
| 结束排练 | 「⏹ 结束排练」锁定记录并跳转复盘；「去复盘」不锁定也可查看 |
| 复盘叠加 | 「复盘」选排练：Canvas 上空心=计划、实心绿=实测、粉线=位置偏差；时间轴上灰点=计划、彩点=实测、连线=时差（红延后/蓝提前） |
| 偏差与漏记 | 左侧节点/演员汇总、右侧偏差明细；漏记/缺席单独标出 |
| 定位与回放 | 点击偏差行/汇总行/时间轴实测点即定位；▶ 沿时间同时回放计划轨迹与实测轨迹 |
| 并排比较 | 勾选「并排比较排练 B」，双 Canvas 对照，并汇总**反复迟到节点**与**反复走位偏移** |
| 复制到新副本 | 偏差明细勾选实测时间/位置（或「全选」）→「⧉ 生成编排副本」，在新舞台上修订，原方案不变 |
| 可打印复盘单 | 顶栏「🖨 复盘单」，按节点与按演员汇总提前/延后、偏差、漏记、缺席、备注；比较时附两场对照 |

复盘判定阈值：节点/演员时差绝对值 ≥ **1.0s** 计为提前或延后；位置偏差 ≥ **0.5m** 计为走位偏移
（可在 `stageplanner/review.py` 调整 `LATE_THRESHOLD`、`POSITION_THRESHOLD`）。
数据模型：排练存 `rehearsals`（含快照 JSON、时钟状态、总备注）、节点打点
`rehearsal_beat_marks`、演员打点 `rehearsal_actor_marks` 三张表。

## 问题检测规则

- **无法按时到位**：相邻节点路径长度 ÷ 演员常用步速 > 到位时间差，路径标红并显示
  所需步速。
- **穿越障碍**：路径任一折线段与障碍多边形规范相交；起止点停靠在障碍顶点合法。
- **演员碰撞**：按 0.5s 时间采样全场轨迹，两演员距离 < 0.7m 时警告。
- 检测逻辑前后端一致（`stageplanner/analysis.py` 与 `static/app.js` 内各一份），
  前端实时显示，打印页使用服务端结果。

## 项目结构

```
stageplanner/
  app.py          Flask 应用工厂、REST 与打印路由（含排练/复盘/比较/回写）
  db.py           SQLite schema 与整文档 upsert、排练记录 CRUD
  geometry.py     线段相交 / 点在多边形内 / 折线长度
  analysis.py     走位问题检测、打印派生数据
  review.py       排练快照、偏差计算、双场比较、选择性回写新副本、复盘单派生
  templates/      index.html、print_cues.html、print_overview.html、print_review.html
  static/         app.js（Canvas 编辑器）、rehearsal.js（排练实录与复盘）、style.css
tests/test_app.py pytest 端到端测试
```
